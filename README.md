# ClusterApp
Лабораторная работа №4 — Базы знаний и поддержка принятия решений

[![Cluster Analysis CI](https://github.com/ilyakolos777/ClusterApp/actions/workflows/main.yml/badge.svg)](https://github.com/ilyakolos777/ClusterApp/actions/workflows/main.yml)

Программный комплекс для машинного обучения «без учителя». Приложение демонстрирует, как искусственный интеллект способен самостоятельно находить скрытые закономерности в хаосе данных и разделять объекты на смысловые группы (кластеры). 

На примере базы из 300 автомобилей система анализирует три характеристики (Мощность, Расход топлива, Разгон) и объединяет их в категории («Городские авто», «Кроссоверы», «Спорткары»), используя два классических алгоритма: метод K-Средних и метод Максимина.

---

## Архитектура проекта

Проект разделен на логические модули, что делает код читаемым и удобным для модификации:

* `data_provider.py` — хранилище базы данных автомобилей и математическая функция расчета взвешенного (нормализованного) евклидова расстояния для уравнивания разных единиц измерения.
* `kmeans.py` — математическое ядро алгоритма K-Средних, который группирует объекты вокруг заданного количества центров (центроидов).
* `maximin.py` — математическое ядро эвристического алгоритма Максимина, который способен самостоятельно вычислять необходимое количество кластеров, опираясь на геометрию данных.
* `ui.py` — интерактивный графический интерфейс с системой «живой аналитики», построенный на фреймворке PyQt6 и библиотеке PyQtGraph.
* `main.py` — главный исполняемый файл, запускающий программу.

## Подробная инструкция по использованию программы

Сразу после запуска приложение автоматически загружает встроенную базу из 300 автомобилей, вычисляет их математические сходства и разбивает на группы. На экране появится главный дашборд, разделенный на три функциональные зоны: 
1. **Панель управления** (слева) — для настройки параметров;
2. **Визуализатор графиков** (в центре) — для геометрического анализа;
3. **Панель вердикта** (справа) — для текстовой расшифровки результатов.

### Шаг 1. Выбор осей для 3D-графика (Блок «1. Проекция графика»)
Каждая машина в базе имеет 3 ключевых параметра (Мощность, Расход, Разгон), что образует трехмерное пространство (3D). Так как экран плоский, система позволяет выбрать, какие две из трех осей отображать в данный момент.
* В выпадающих списках выберите интересующие вас параметры для **оси X** и **оси Y**. 
* График в центральной части экрана перестроится мгновенно. *Пример: выбрав «Мощность» и «Разгон», вы сможете наглядно увидеть, как кластер мощных спорткаров физически отделяется от экономичных малолитражек.*

### Шаг 2. Тестирование нового автомобиля (Блок «2. Параметры новой машины»)
Вы можете проверить, как экспертная система классифицирует совершенно новую, неизвестную ей машину.
* Двигайте ползунки характеристик: **Мощность**, **Расход**, **Разгон**.
* На графике в центре появится большая **белая звезда** — это ваш созданный автомобиль. Она будет перемещаться в реальном времени вслед за движением ползунков, демонстрируя свое положение относительно известных классов.

### Шаг 3. Настройка алгоритма Максимина
В отличие от алгоритма K-Средних, которому нужно жестко задать количество групп, эвристический метод Максимина принимает решения самостоятельно на основе порогового коэффициента `Alpha`.
* Изменяя `Alpha` в коде, вы регулируете «геометрическую чувствительность» алгоритма. 
* Если сделать порог слишком высоким, Максимин сольет все машины в одну большую группу. Если слишком низким — разобьет выборку на множество мелких фрагментов. Оптимальное значение позволяет алгоритму безошибочно находить скрытые классы.

### Шаг 4. Работа с графической панелью (По центру)
В центральной части доступны две вкладки для визуального сравнения работы алгоритмов (K-Средних и Максимин):
* **Круглые точки** — это все 300 автомобилей из обучающей базы. Цвет точки означает принадлежность к конкретному найденному кластеру.
* **Цветные крестики** — это вычисленные математические «центры масс» каждой группы (центроиды).
* **Светло-серая пунктирная линия** — наглядно показывает, к какому именно центру масс (и кластеру) алгоритм привязал вашу новую машину (белую звезду).
* *Навигация:* График полностью интерактивен. Его можно масштабировать (отдалять/приближать) колесиком мыши, а также перемещать в стороны, зажав левую кнопку мыши.

### Шаг 5. Чтение экспертных результатов (Блок «Живая аналитика»)
Правая панель переводит сложные математические вычисления на понятный человеческий язык. Данные здесь обновляются мгновенно при любом движении ползунков или переключении вкладок алгоритмов.
* **Вердикт:** Система выводит смысловое название группы, к которой отнесена ваша новая машина (например, «Спорткары» или «Городские авто»).
* **Уверенность (Дистанция):** Показывает точное математическое расстояние от вашей звезды до крестика центроида. 
  * Если дистанция минимальна — система уверена в ответе (машина находится в самом ядре класса). 
  * Если дистанция велика — система выдаст предупреждение, что объект является аномалией и находится далеко на периферии.
* **Профиль кластеров:** Сводка по всем найденным группам. Показывает, сколько машин попало в каждый класс и каковы усредненные (идеальные) характеристики представителя этой группы.
